# Concepto

The activity feed is the workspace audit log: it records what each team member did and when. Every event shows the actor, the action and, where applicable, a direct link to the related object.

:::cards
- **Create / Restore** — new projects, catalogues, templates or other resources.
- **Edit / Rename** — changes to existing resources.
- **Delete** — removals of any element.
- **Sistema** — automatic actions with no human actor (imports, document generation).
:::

:::tip{tone=info title="Required permission"}
Only members with the **audit:view** permission can see the feed. If the screen shows an access error, contact your organisation administrator.
:::

# Tutorial

## Browsing activity

:::steps
1. Open **Actividad** in the side menu.
2. The feed shows the 25 most recent events, newest first.
3. Click **Cargar más** to page through older events.
4. Click the link icon on any row to go directly to the related object.
:::

:::callout{tone=info}
The counter at the bottom shows how many events are loaded out of the total. The page does not refresh automatically — re-open it or reload to see the latest activity.
:::
