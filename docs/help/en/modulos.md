# Concepto

The marketplace is the catalogue of commercial modules that extend Sunalyze's capabilities. Each module is an optional functional block: activate it with one click and it becomes available immediately across the entire organisation.

:::cards
- **Active module** — already enabled in your workspace; shown with the «Active» badge.
- **Inactive module** — available to subscribe; shows the price in €/month or «Included» if it is part of your plan.
- **No modules** — the catalogue is empty when no modules have been published yet.
:::

:::tip{tone=info title="Required permissions"}
Only users with the **module:manage** permission (usually the organisation administrator role) can activate or deactivate modules. Other users see the catalogue and the message «Ask an administrator».
:::

# Tutorial

## Activating a module

:::steps
1. Go to **Modules** in the sidebar — URL `/app/modulos`.
2. Find the card of the module you want to activate.
3. Click **Activate**: the module is enabled instantly for the entire organisation.
4. If the module requires additional configuration, use the **Help** link on the card to read the specific documentation.
:::

## Deactivating a module

:::steps
1. Find the card showing the «Active» badge.
2. Click **Active · Deactivate** — the button shows both actions.
3. The module is deactivated and becomes inaccessible for all organisation members.
:::

:::callout{tone=warning}
Deactivating a module hides its functionality immediately; associated data is not deleted and is restored when the module is re-activated.
:::
