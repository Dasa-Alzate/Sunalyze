# Concepto

La papelera guarda los proyectos y catálogos que has eliminado. Los elementos permanecen aquí hasta que los restaures; la eliminación definitiva no se expone en la interfaz.

:::cards
- **Proyectos** — proyectos eliminados accesibles para usuarios con permiso **project:delete**.
- **Catálogos** — catálogos eliminados accesibles para usuarios con permiso **catalog:manage**.
:::

# Tutorial

## Restaurar un proyecto o catálogo

:::steps
1. Abre **Papelera** en el menú lateral.
2. Localiza el elemento en la sección **Proyectos** o **Catálogos**.
3. Pulsa **Restaurar** a la derecha del elemento.
4. Confirma en el diálogo que aparece; el elemento vuelve a su lista original al instante.
:::

:::tip{tone=success}
Después de restaurar un proyecto aparece de nuevo en tu lista de proyectos con todos sus datos intactos. Los catálogos restaurados vuelven a tu biblioteca de equipos.
:::

:::callout{tone=warning}
Si la papelera está vacía o no ves ciertos elementos, puede que no tengas los permisos necesarios. Habla con el administrador de tu organización.
:::
