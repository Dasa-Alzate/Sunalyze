# Concepto

El feed de actividad es la bitácora de auditoría del espacio de trabajo: registra qué hizo cada miembro del equipo y cuándo. Cada evento muestra el actor, la acción y, cuando aplica, un enlace directo al objeto relacionado.

:::cards
- **Crear / Restaurar** — nuevos proyectos, catálogos, plantillas u otros recursos.
- **Editar / Renombrar** — cambios sobre recursos existentes.
- **Eliminar** — borrados de cualquier elemento.
- **Sistema** — acciones automáticas sin actor humano (importaciones, generación de documentos).
:::

:::tip{tone=info title="Permiso necesario"}
Solo los miembros con el permiso **audit:view** ven el feed. Si la pantalla muestra un error de acceso, contacta con el administrador de tu organización.
:::

# Tutorial

## Consultar la actividad

:::steps
1. Abre **Actividad** en el menú lateral.
2. El feed muestra los 25 eventos más recientes ordenados de más a menos reciente.
3. Pulsa **Cargar más** para paginar los eventos anteriores.
4. Haz clic en el icono de enlace de cualquier fila para ir directamente al objeto relacionado.
:::

:::callout{tone=info}
El contador inferior muestra cuántos eventos tienes cargados del total. La página no se refresca sola: vuelve a entrar o recarga para ver la actividad más reciente.
:::
