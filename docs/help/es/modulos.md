# Concepto

El marketplace es el catálogo de módulos comerciales que amplían las capacidades de Sunalyze. Cada módulo es un bloque funcional opcional: se activa con un clic y queda disponible de inmediato para toda la organización.

:::cards
- **Módulo activo** — ya está habilitado en tu espacio; aparece con la etiqueta «Activo».
- **Módulo inactivo** — disponible para contratar; muestra el precio en €/mes o «Incluido» si está en tu plan.
- **Sin módulos** — cuando el catálogo está vacío aún no hay módulos publicados por el administrador de la plataforma.
:::

:::tip{tone=info title="Permisos necesarios"}
Solo los usuarios con el permiso **module:manage** (normalmente el rol de administrador de la organización) pueden activar o desactivar módulos. El resto de usuarios ven el catálogo y el mensaje «Pídelo a un administrador».
:::

# Tutorial

## Activar un módulo

:::steps
1. Ve a **Módulos** en el menú lateral — URL `/app/modulos`.
2. Localiza la tarjeta del módulo que quieres activar.
3. Pulsa **Activar**: el módulo queda habilitado al instante para toda la organización.
4. Si el módulo requiere configuración adicional, usa el enlace **Ayuda** de la tarjeta para consultar la documentación específica.
:::

## Desactivar un módulo

:::steps
1. Localiza la tarjeta con la etiqueta «Activo».
2. Pulsa **Activado · Desactivar** — el botón muestra ambas acciones.
3. El módulo se desactiva y deja de estar accesible para los miembros de la organización.
:::

:::callout{tone=warning}
Desactivar un módulo oculta su funcionalidad de inmediato; los datos asociados no se eliminan y se recuperan al volver a activarlo.
:::
